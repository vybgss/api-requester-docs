Features

The depth of a desktop tool, in your pocket

Build requests

  • Smart address bar that highlights host, path, query and variables
  • GET, POST, PUT, PATCH and DELETE
  • Query parameters as rows, always in sync with the URL
  • Headers with autocomplete, one-tap templates and on/off toggles
  • JSON body editor with live validation, Beautify and Minify
  • Auth helper for Bearer tokens, Basic auth and API keys
  • Paste a cURL command and the method, URL, headers and body are filled in

Environments

  • Keep base URLs and tokens in {{variables}} for Production, Staging, Local or anything else
  • Each environment gets its own color, so you always know where a request goes
  • Switch in a tap; undefined variables are highlighted before you send
  • Export with variables substituted, or keep them as placeholders

Inspect responses

  • Status, duration, size and content type at a glance
  • Pretty, Tree and Raw views for JSON, image preview and instant search
  • Copy a value, a path or a whole sub-tree from the JSON tree
  • Response headers with filter and copy
  • Timing waterfall: DNS, TCP, TLS, server time and download, plus protocol and TLS version

Organize and share

  • Saved requests with names, search and undo
  • History grouped by day, with status and timing for every call
  • Export to cURL, HTTPie, JavaScript fetch, Python requests or Swift URLSession
  • Saved requests, history and environments sync through iCloud
